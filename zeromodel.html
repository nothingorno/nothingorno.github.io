ZeroModel is a web-based 3D low-poly box modeling environment built for rapid asset creation and C++ game engine integration.

Shortcuts & Keybinds:
• W / E / R: Switch Gizmos (Translate / Rotate / Scale)
• Ctrl + Z / Ctrl + Y: Undo / Redo Actions
• Delete / Backspace: Delete Selected Block
• Shift + D: Duplicate Selected Block
• Orbit Camera: Left-click + drag
• Pan Camera: Right-click + drag
• Context Menu: Right-click on empty viewport
