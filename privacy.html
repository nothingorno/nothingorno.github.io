Effective Date: November 1, 2026 App: Commit Bot / GitHub Changelog Bot Operator: NothingOrNo (nothingorno)

info 1. Introduction

This Privacy Policy describes how information is collected, used, and handled when you use our Discord bot and associated web services (hosted on Fly.io and linked with GitHub repositories). We respect your privacy and are committed to protecting any data processed by the application.

database 2. Information We Collect

The application interacts with public platforms (GitHub and Discord) and collects only the minimum data necessary to perform its core function: tracking repository updates and posting changelogs.

  • GitHub Repository Data: The bot queries public data from designated GitHub repositories (such as nothingorno/nothingorno.github.io). This includes public commit messages, commit SHAs, author names, code statistics (additions/deletions), and lists of modified files. No private repositories or private user data are accessed unless explicitly authorized via secure tokens.
  • Discord Integration Data: The bot interacts with Discord servers and channels where it has been installed. This includes channel IDs configured for automated posts and command interactions (such as /check or !ping).
  • Technical Logs: Basic server and connection logs may be temporarily processed by our hosting provider (Fly.io) to ensure service stability, uptime, and security.

settings_suggest 3. How We Use Information

The collected information is used strictly for the following purposes:

  • To automatically fetch and format public commit logs from GitHub.
  • To deliver real-time notifications and changelog embeds to your configured Discord channels.
  • To respond to manual user commands (/check, /status, /ping).
  • To maintain application stability and debug technical errors.

shield 4. Data Sharing and Disclosure

We do not sell, trade, or otherwise transfer your data to outside parties. All data processed by the bot remains strictly between GitHub, Discord, and our secure hosting environment.

open_in_new 5. Third-Party Services

Our application relies on third-party APIs and infrastructure. Their respective privacy policies govern their handling of data:

  • Discord API & Platform: Discord Privacy Policy
  • GitHub API & Platform: GitHub Privacy Statement
  • Fly.io Hosting: Fly.io Privacy Policy

history 6. Data Retention

The bot operates in real-time. It does not maintain a permanent database of user messages or personal data. Commit identifiers (SHAs) are kept temporarily in memory solely to prevent duplicate notifications.

update 7. Changes to This Privacy Policy

We may update this Privacy Policy from time to time. Any changes will be reflected directly on this page with an updated effective date.
